仕様: transport.charge(payload, idempotency_key=key) は失敗時 TimeoutError を返す。同じ論理決済の内部リトライでは同一キーを使う。別の pay 呼出しは別決済。3回まで試行し、最後の TimeoutError は呼出元へ返す。TimeoutError 以外は即座に伝播。
実装:
import uuid
def pay(transport, payload):
    for attempt in range(3):
        try:
            return transport.charge(payload, idempotency_key=str(uuid.uuid4()))
        except TimeoutError:
            if attempt == 2:
                raise
